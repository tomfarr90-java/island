

# 🏝️ Island Simulation
**Многопоточная экосистема дикой природы**


---

### 📖 Описание проекта

Многопоточное консольное приложение на Java, имитирующее жизнь дикой природы на изолированном острове.
Проект демонстрирует применение принципов **ООП**, сложных алгоритмов взаимодействия объектов и глубокое использование **Multithreading**.

## 🚀 Ключевые особенности

### ⚙️ Многопоточность (Concurrency)

* **ScheduledExecutorService**: Управляет тремя независимыми задачами (жизнь животных, рост растений, вывод статистики).
* **Parallel Stream**: Обработка каждой локации острова происходит параллельно, что позволяет симулировать миллионы объектов одновременно.
* **CopyOnWriteArrayList**: Использование потокобезопасных коллекций для предотвращения ошибок.

### 🧬 Логика и Баланс

* **Config Driven**: Все параметры вынесены в `OrganismConfig.yaml`.
* **Метаболизм**: Реализована система голодания. Животное погибает при потере **50%** от своего веса.
* **Умное питание**: Учитывается приоритет пищи (например, утка ест и гусениц, и траву).
